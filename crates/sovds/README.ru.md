# sovds — Sovereign Dataset Toolkit

[🇬🇧 English](README.md) | 🇷🇺 Русский

Собирайте **размеченные датасеты с ground-truth-метками из живых систем** —
собирайте телеметрию, безопасно и осознанно вызывайте сбои с указанием
происхождения, сегментируйте поток на *эпизоды* сбоев и измеряйте детекцию и
безопасность отката. Так набор правил мониторинга (или будущая модель) можно
проверить на реальном поведении системы, а не на догадках.

`sovds` **доменно-агностичен**: он ничего не знает о роутерах, сервисах или
конкретной системе. Вы подключаете свой мир через один трейт и получаете весь
конвейер датасета бесплатно.

## Зачем

Построен по внутренним инженерным принципам проекта:

- **Ноль зависимостей, агностичное ядро.** Никаких сторонних
  крейтов. Ядро компилируется под `no_std` (файловые части — за фичей `std`,
  включённой по умолчанию). Встраивайте без хвоста зависимостей; собирайте
  офлайн с зафиксированным тулчейном хоть через десять лет.
- **Невозможность невалидных состояний.** Запись разделяет
  происхождение (`Source`), *диагностированный* сбой и *метку ground-truth-
  инъекции* — «мы сломали это специально» никогда не спутать с реальным сбоем.
- **Ограниченность, без паники.** `#![forbid(unsafe_code)]`;
  линты запрещают `unwrap`/`expect`/`panic`/индексацию/переполнение. Ничего не
  паникует и не переполняется на враждебном вводе; битая строка лога
  считается и пропускается, никогда не фатальна.

## Контракт

Реализуйте [`Domain`] один раз для своей системы, объявив три типа и то, как
они сериализуются в строку записи:

```rust
use sovds::domain::{Accept, Domain, ParseError};
use core::fmt;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
struct Host;                                   // тег вашего домена

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
enum Res { Ok, CpuSaturated, MemPressure }     // словарь ваших сбоев

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
struct Load { cpu_pct: u8, mem_pct: u8 }       // ваше наблюдение

impl Domain for Host {
    type Obs = Load;
    type Fault = Res;
    type Annot = bool;             // любой доп. токен на запись (напр. "было ли действие?")
    type Builder = /* небольшой аккумулятор для парсинга */;

    fn healthy() -> Res { Res::Ok }
    fn faults() -> &'static [Res] { &[Res::Ok, Res::CpuSaturated, Res::MemPressure] }
    fn fault_label(f: Res) -> &'static str { /* написание в проводе */ }
    fn parse_fault(s: &str) -> Option<Res> { /* обратное */ }
    fn write_obs<W: fmt::Write>(w: &mut W, o: &Load) -> fmt::Result { /* " cpu=.. mem=.." */ }
    fn write_annot<W: fmt::Write>(w: &mut W, a: &bool) -> fmt::Result { /* " shed=.." */ }
    fn accept(b: &mut Self::Builder, key: &str, val: &str) -> Result<Accept, ParseError> { /* .. */ }
    fn finish(b: Self::Builder) -> Result<(Load, bool), ParseError> { /* .. */ }
}
```

Это всё. Полную рабочую версию см. в
[`examples/host_monitor.rs`](examples/host_monitor.rs):

```sh
cargo run -p sovds --example host_monitor
```

## Что вы получаете

| Модуль | Фича | Что делает |
|--------|---------|--------------|
| `record` | core | `Record<D>` + одна самоописательная строка `key=value`; порядко-независимый, безопасный к враждебному вводу парсинг |
| `episode` | core | сегментирует поток записей на эпизоды сбоев (единица анализа — независимые инциденты, а не строки) |
| `injection` | core | детекция по окнам (`detected`/`missed`/`silent`) + безопасность отката (`recovered`/`stuck`/`pending`) над инъецированными сбоями |
| `stats` | core | целочисленные оценщики с фиксированной точкой (EWMA, ограниченный односторонний CUSUM) |
| `dataset` | std | загружает ротируемый лог обратно в `Corpus<D>`, устойчив к битым строкам |
| `recorder` | std | надёжный атомарный append с ограниченной ротацией поколений |
| `readiness` | std | сводка эпизодов по классам — «данных для обучения уже достаточно?» |

## Формат записи

Одна строка на цикл наблюдения. Токены разметки принадлежат тулкиту; ваш
домен владеет своими токенами наблюдения/аннотации:

```
t=<tick> ts=<unix> probed=<0|1> class=<fault> src=<live|backfill|synth> [inject=<fault>] <ваши obs-токены> <ваши annot-токены>
```

Парсер порядко-независим, так что лог, записанный в старой раскладке, всё
равно загрузится. `inject=` присутствует только когда сбой был **вызван
намеренно** — эта метка отделяет ground truth от органического поведения.

## Установка

```toml
[dependencies]
sovds = { path = "…/sovds" }             # no_std + std (по умолчанию)
# или, для no_std-встраивания:
sovds = { path = "…/sovds", default-features = false }
```
