# Sovereign dataset format

The durable output of the brain is one thing: an append-only log of **records**,
one per supervision cycle, on the laptop (never on router flash). This document is
the stable contract for that data — what a field means, its units, and how the
format may evolve — so the dataset stays readable for the long haul (set of principles:
longevity) and a future trainer has a written schema, not folklore.

The canonical serializer/parser is `sovereign_core::record`
(`write_record` / `parse_record`); this file documents what they emit. If the two
ever disagree, the code is authoritative and this file is the bug.

## Record line

One record is a single line of space-separated `key=value` tokens, e.g.:

```
t=0 ts=1784355097 probed=1 wan=up:36418 sb=running tun=ok:147 dns=ok \
nodes=1:143,2:232,3:440,4:137 wanok=1 load=11 mem=250116 active=1 \
verdict=warming class=none state=healthy reason=nominal action=observe \
outcome=- src=live
```

(shown wrapped; a real record is one physical line, no trailing newline before the
recorder adds it). Tokens appear in the order below. A `-` value means "not
measured / not applicable", never a fake zero.

| key | type / values | unit | meaning |
|-----|---------------|------|---------|
| `t` | u64 | cycles | Logical tick within a collector run. **Resets to 0 at each run start** — it is a per-run clock, not a global timeline. Required. |
| `ts` | u64 | Unix seconds | Wall-clock stamp. `0` = unknown (records written before timestamps existed). The only cross-run timeline. Optional (defaults 0). |
| `probed` | `0` \| `1` | — | Whether the router was actually observed this cycle. `0` = the brain ran degraded (probe failed → all-Unknown telemetry). Required. |
| `wan` | `up:<uptime_s>` \| `down` \| `unknown` | uptime in s | WAN session state. `up:N` = PPPoE session up N seconds. `unknown` = not measured (treated as not-a-fault). Required. |
| `sb` | `running` \| `dead` \| `unknown` | — | sing-box process liveness. Required. |
| `tun` | `ok:<lat>` \| `deg:<lat>` \| `dead` \| `unknown` | latency in ms | Tunnel data-path health through the selected node. `deg` = degraded. Required. |
| `dns` | `ok` \| `failing` \| `unknown` | — | Name-resolution probe result. Required. |
| `nodes` | `<id>:<lat>` / `<id>:x`, comma-sep, or `-` | latency in ms | Per-exit-node latency this cycle; `id:x` = seen but unmeasured; `-` = none. Optional (defaults empty). |
| `wanok` | `1` \| `0` \| `-` | — | Real reachability **through** the WAN (curl to a neutral host). `0` = session may be up but blackholed. `-` = unmeasured. Optional (aux, defaults `-`). |
| `load` | u32 \| `-` | load×100 | Router 1-minute load average, integer fixed-point (`load=150` ⇒ 1.50). Optional. |
| `mem` | u32 \| `-` | KiB | Router `MemAvailable`. Optional. |
| `active` | u8 \| `-` | node id | Exit node the urltest group currently routes through. Optional. |
| `verdict` | `warming` \| `healthy` \| `slow` \| `throttled` \| `down` | — | Adaptive path verdict (the fleet's judgement relative to the node's learned baseline). Required. |
| `class` | `none` \| `wan_down` \| `singbox_dead` \| `node_dead` \| `node_degraded` \| `dns_fail` | — | The single fault the (refined) observation classified to. Required. |
| `state` | `healthy` \| `suspect:<class>:<seen>` \| `cooldown:<class>:<level>:<until>` | — | Supervisor FSM state after this cycle. Required. |
| `reason` | `nominal` \| `first_suspicion:<class>` \| `awaiting:<class>:<seen>` \| `recovered` \| `confirmed:<class>:<level>` \| `cooling` \| `escalated:<class>:<level>` | — | Machine-readable why of the transition. Required. |
| `action` | `observe` \| `switch_node` \| `restart_singbox` \| `bounce_wan` \| `failover_backup` \| `reboot` | — | Remedy chosen (in dry-run, what *would* have been done). Required. |
| `outcome` | `-` \| `verified` \| `unverified` \| `dryrun` | — | Result of the action. `-` = no action warranted. `verified` = issued and post-condition confirmed. `unverified` = issued but not confirmed. `dryrun` = decided but deliberately **not** issued (observe-only mode) — never conflated with `verified`. Required. |
| `src` | `live` \| `backfill` \| `synth` | — | Provenance. `live` = observed by the running brain. `backfill` = recovered from the router's RAM buffer after a laptop-off gap (never actuated). `synth` = generated by the scenario suite (`sovereign-scenario`), never observed. Optional (defaults `live`). |
| `inject` | fault class | — | **Ground-truth injection label**: present only when the record was taken during a *deliberately induced* fault (a `sovereign-inject` marker was active), giving the class we induced on purpose. **Absent = organic.** This is what separates "we broke it on purpose" from a real problem: compare `inject` (what we induced) to `class` (what the rules diagnosed) to measure detection on genuine router behaviour. The decision core never reads it. Optional. |

### Invariants & evolution rules

- **Backward compatible by construction.** Every field added after v1 (`ts`,
  `nodes`, `wanok`/`load`/`mem`/`active`, `src`) parses as its "unmeasured"
  default when absent, so old lines still load. New fields MUST keep this
  property — append optional tokens, never repurpose an existing key.
- **Hostile input is rejected, not trusted.** A malformed value or unknown key
  fails the parse for that line; the loader skips and counts it, never crashes
  (`dataset::load`).
- **Units are fixed-point integers**, never floats: `load` ×100, latency in whole
  ms, memory in KiB. This keeps the data bit-identical across machines.
- **`t` is per-run**; use `ts` for a global timeline, and treat a `t=0` as a run
  boundary (a discontinuity in observation).

## Episodes (the training/analysis unit)

Rows are not the unit a model learns from — **episodes** are. An episode is a
contiguous stretch in one fault class, from onset to recovery. `sovereign_core::episode`
segments the record stream into them; `sovereign-episodes` reports them.

Segmentation rules:

- An episode is a maximal run of one non-`none` `class`.
- A **brief healthy flicker** (up to `gap_tolerance` cycles, default 5, matching
  the supervisor's `confirm_threshold`) is folded into the same episode — a fault
  that clears for one cycle and returns is one incident.
- An episode **never crosses a run boundary** (`t=0`) — live and back-filled runs
  interleave in file order but are segmented independently.
- Each episode carries: class, onset tick/time, duration, fault-cycle count,
  tolerated-flicker count, actions taken, peak action, how it ended
  (`recovered` / `transition` / `restart` / `ongoing`), and provenance.

"Training-readiness" is measured in **independent episodes per class**, not rows:
a healthy network yields the rare classes (wan_down, singbox_dead, dns_fail) very
slowly, which is why the scenario suite exists to seed them.

## Where the data lives

- Laptop, canonical: `~/.local/share/sovereign/records.log` (+ rotated `.1..N`),
  the system of record. Bounded rotation, never unbounded on disk.
- Router, transient fallback only: `/tmp/sovereign-buffer.log` — a RAM ring buffer
  (~14 days, see `deploy/router/sovereign-probe`) drained loss-free into the log
  by `sovereign-backfill` when the laptop returns. Never persisted to flash.
